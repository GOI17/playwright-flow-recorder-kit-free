# Security

Playwright Flow Recorder Kit is local-first. Version 0.1 stores recorded
journeys in Chrome storage and has no Alfred Labs backend or mandatory
telemetry.

Do not record or send passwords, payment-card details, authentication tokens,
customer data, confidential source code, or other secrets. Pattern-based
placeholder replacement reduces common exposure but cannot detect every
sensitive value. Review every recording and export before sharing it.

To report a vulnerability privately, contact
`alfredlabs.help@gmail.com`. Do not include secrets or customer data in the
initial report.
